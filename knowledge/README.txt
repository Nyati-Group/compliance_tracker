Put the reference documents for the "Ask AI" assistant in this folder, then restart the server:

  - the UDCPR PDF   (e.g. UDCPR-2020.pdf)
  - the RERA Act / MahaRERA rules PDF   (e.g. RERA-Act-2016.pdf)
  - optional: MahaRERA circulars, UDCPR amendment notifications (PDF, .txt or .md)

The file name (without extension) is shown as the source name in answers, so name files clearly.
Text-based PDFs only: scanned (image) PDFs have no text to read and need OCR first.
The compliance register (app/items.json) and live tracking data are always included automatically.
